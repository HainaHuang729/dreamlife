# 青苔小站

根据林间铁路参考图创作的 Three.js 网页场景。正交相机、低分辨率像素渲染、程序化树林与建筑，无外部图片资源。

## 运行

```sh
npm install
npm run dev -- --port 5176
```

打开 http://127.0.0.1:5176 。`npm run build` 生成可静态托管的 `dist/`。

## 操作与检查

- WASD / 方向键：在站台范围内移动；移动到边缘应停止。
- 拖拽：旋转视角；滚轮 / 双指：缩放；⟲：复位。
- E / 双击场景：与附近的白发旅人交谈。
- 下一班列车：驶入、停靠 6 秒、离站，运行时按钮禁用，结束后可再次呼叫。
- 入夜 / 天亮：切换环境光、车站灯光、时钟和天气文字。
- 声音：用户开启后播放程序生成的风声，再次点击关闭。
- 手机屏幕提供方向按钮。

这是 Three.js 场景体验原型，环境音为合成风声。

## 晨谷生活：五张独立设计的新地图

新地图从头设计空间布局，不沿用旧地图大纲。左侧按钮切换场景，地图里的路口和门口也能按 E 切换。日夜状态共用，当前页面内保留收菜和交菜状态；刷新后重置，不包含完整经营或存档系统。

| 场景 | 新构图 | 互动位置 |
| --- | --- | --- |
| 老宅农场 | 井院、左侧连屋、斜向菜畦、后方小池、前景果树 | 菜畦旁浇水和收获、井边取水、老宅门前进入室内 |
| 村口主街 | 绕树院弯行的小路、错位店铺、两处集市摊 | 公告栏、收菜亭、茶铺 |
| 河湾竹桥 | 蜿蜒河道、拱形竹桥、独立听水亭、分散竹丛 | 支渠开闸、听水亭休息、两岸路口 |
| 梯田民宿 | 弧形田埂、曲线台阶、偏置山舍和观景台 | 山舍喝茶、日落台坐下 |
| 老宅室内 | 开放起居间、侧面睡眠隔间、阅读长桌、右侧灶台 | 猫窝、相册、茶桌、床铺、出门 |

走近物件后右下角显示可操作内容。WASD / 方向键移动，E 或“附近互动”执行；起身只需再次移动。

`npm test` 检查五张地图生成、收菜跨场景交付、往返状态、河岸阻挡与过桥、台阶登顶、室内边界及昼夜更新；`npm run build` 检查生产构建。
