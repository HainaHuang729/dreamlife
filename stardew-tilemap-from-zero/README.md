# Tilemap From Zero

当前代码版本：`v0.2.0`

当前美术线版本：`art-0.2.18`

当前动作模组版本：`motion-0.2.7`

这是一个纯 HTML/CSS/JavaScript 的 2D Tilemap 原型，对应 `stardew-valley-tilemap-from-zero.md` 里的核心结构。

版本规则：功能、体验或内容更新递增 `src/main.js` 里的 `APP_VERSION`、页面代码版本标识和 README 当前代码版本。纯美术表现迭代只递增 `ART_VERSION`，不占用代码线版本号。

## 运行

直接打开 `index.html` 即可运行，不需要构建步骤。

## 春季推荐路线

第一年春季的目标是先把节奏跑通：第 1-5 天开垦右上角小片农田、播种、浇水、睡觉成长、收获并完成第一次出货；随后去村庄公告栏查看反馈，修复杂货铺，并第一次去村庄种子铺补货。第 11 天后走北侧山路采集木料、石料、煤、旧铁件、铜矿和山野菜。第 13-15 天春集是早豆和工具材料的机会，但错过也不拦住夏季主线。第 21 天后春季样本箱开放，样本包允许后续年份继续补齐；春末目标是至少一个村民支线，并保留约 200g 作为夏季启动资金。

## 一周目最短路线

- 春季：完成第一次出货，去村庄修复杂货铺，开放山里资源点，参加或记录春集，样本箱可跨年补齐。
- 夏季：围绕稳定供货和社区订单推进，至少完成 1 个村民支线和 1 个村情目标。
- 秋季：完成电商试单，修复加工桶，提交合作社样品，开始把作物转成加工/订单收益。
- 冬季：补齐村情目标，至少把 1 座设施推进到强化二，完成年终会并选择第二年路线。
- 土地庙最终：检查主线、村情、水质、第二年路线和路线设施强化二，全部达成后触发最终追问与一周目回顾。

## v0.2.0 演示验收

- 无素材模式：不带 `?assets=1` 时继续使用 Canvas 色块 fallback，移动、工具、对话、存档和任务推进不依赖 PNG。
- 美术模式：带 `?assets=1` 时加载作物、设施、山里资源点、建造物、主线/节庆对象、水产、UI 和工具图标；缺图会在开发面板审计里显示，不阻塞游玩。
- 正式入口：玩家用 `Q` 查任务，`Tab` 查日历/图鉴/村庄变化，`M` 查小地图，`B` 建造，`Esc/P` 系统菜单；`F2` 仅作为开发面板。
- 一周目入口：春夏秋冬、土地庙最终、第二年路线都能从任务面板、路牌、小地图或土地庙找到下一步。
- 验收页：`Q -> 通关验收` 会显示五个一周目节点和 `v0.2.0` 演示验收清单。

## 已实现

- 固定尺寸 Tile 网格
- `ground`、`buildings`、`front`、`collision` 多层地图数据
- 摄像机局部渲染
- 玩家移动与碰撞检测，按住 `Shift` 可跑步加速
- 交互对象：牌子、箱子、传送点

- 设施奖励：托管教室提高任务/社区奖励，青年工坊降低建造成本，老人饭点和巡诊路线提高体力上限，冷链提高出售/出货收益，村塘清淤逐级改善水质和水产解锁
- 年终评价：第一年大寒第五天睡觉后触发年度总结，列出村庄现实变化，按农场评价分数发放一次性年终补助并记录一周目完成
- 第二年方向选择：年终会后可选择合作社扩张、乡村旅游、水利扩建或品牌农产品路线，领取启动补助并切换主线目标
- 乡村旅游路线：选择旅游方向后可修复村庄游客服务亭，提交作物礼篮和加工试吃并达到评价要求后完成第一批游客订单
- 品牌农产品路线：选择品牌方向后可修复村庄品牌包装台，把作物和普通加工品包装成高价值品牌礼盒并完成首批出货奖励
- 水利与扩建路线：选择水利方向后可修复农场旧水泵，启动第一段水渠工程，提升水壶容量并让覆盖区作物睡觉后自动浇水
- 农场建造分区：建造面板会提示右上开局区、南侧菜地、西侧加工区和水渠覆盖区的推荐用途；未解锁区域会给出阻挡原因
- 邮箱系统：农舍旁邮箱按天解锁全年信件，读信可领取一次性金币或季节种子奖励
- 农场扩建：通过公告牌购买固定升级，支持扩展耕地和水井；旧版固定围栏会自动清理，篱笆改为可建造装饰
- 日程系统：天数、时间、体力、系统菜单或屋内床睡觉后作物成长；时间段会显示清晨、白天、傍晚、夜晚和深夜
- 夜晚表现：傍晚后画面逐渐变暗，小路灯夜间增强光晕，深夜会出现回屋睡觉提醒
- 天气系统：显示今天/明天天气，雨天自动给作物浇水
- 操作提示：底部工具栏、地图浮字和对象提示根据当前工具、脚下地块、面前对象和编辑器状态提示下一步操作
- 工具手感：非编辑模式下高亮当前工具作用格，成功/失败操作会在地图上显示短暂浮字反馈
- 音效与轻动画：工具、交易、任务、睡觉和传送有短音效；作物成熟、传送和操作结果有轻量 Canvas 动画
- 提醒状态：内部汇总未读邮件、可交任务、成熟作物、待出货、订单进度、低水量和低体力
- 小地图：按 `M` 可在游戏画面内显示或隐藏小地图浮层，只保留地图图形、玩家点和目标点；右侧小地图卡默认隐藏
- 信息面板收口：右侧侧边栏默认隐藏，正式游玩界面只保留左上日程 HUD、底部工具栏和游戏画面；正式信息与操作入口走 `I/Q/M/B/Tab`，开发面板通过 `F2` 或系统菜单打开
- 开发面板边界：开发面板保留保存/读取/重置、测试跳过、高级存档、编辑器和事件日志；日历、图鉴、成就、村庄变化、提醒和农场评价迁入资料面板
- 动态状态：内部汇总作物成熟/浇水状态和加工设施空闲、加工中、可领取状态，用于提醒和任务推进
- 农场评价：把作物、经济、建造、社区、扩建和图鉴进度汇总成 100 分评分，用于年终评价和奖励
- 脱困保护：读档、传送、退出编辑模式时自动修正非法落点，也可点击脱困或按 `U`
- 测试跳过：打开开发面板后可选择春季完成、夏季集市、秋季加工、冬季年终或土地庙最终测试节点，并拦截自动保存；只有手动保存才会写入存档
- 测试存档安全：测试跳过状态会在保存状态栏高亮提示，避免误以为已经写入正式存档
- `localStorage` 多槽位存档/读档和关键操作自动保存，包含玩家状态、库存、任务、扩建和编辑后的地图数据
- 存档管理：支持 3 个存档槽、导出当前游戏状态 JSON、导入存档 JSON 到当前槽、清除当前槽；旧单一存档会自动迁移到槽 1
- 调试显示：网格和碰撞层
- 编辑模式：图层选择、瓦片画笔、橡皮、碰撞编辑、对象放置/删除/属性编辑、JSON 导入/导出/复制、当前地图重置
- 编辑器安全：阻止把玩家当前位置、出生点、传送入口和传送落点设为阻挡；导入 JSON 时也会校验这些关键格子
- 编辑器撤销：支持撤销/重做地图绘制、碰撞编辑、对象放置/删除、对象属性、JSON 导入和当前地图重置

## 美术资源接入规范

- 代码线当前资源契约版本：`0.1.28`；美术线可以继续独立递增 `ART_VERSION`。
- 素材尺寸、占地、锚点、碰撞和排序规则见 `ART_ASSET_SIZE_BIBLE.md`；`32x32` 是地图网格单位，不是所有素材的固定尺寸。
- 第一批测试素材的生成提示词见 `ART_TEST_ASSET_PROMPTS.md`，用于统一 canvas 尺寸、footprint、anchor 和风格描述；人物动作帧按单帧 PNG 生成，不使用需要裁切的 sprite sheet。
- 默认不强制加载外部图片，继续使用 Canvas 色块 fallback；调试素材加载时在 URL 加 `?assets=1`。
- 推荐路径：`assets/game/<group>/<id>--<state>.png`；`state` 为 `default` 时也可使用 `<id>.png`。
- 玩家动作帧推荐路径：`assets/game/player/<action>_<direction>.png`，例如 `walk_down.png`、`hoe_right.png`、`fishingRod_up.png`。
- 分组：`tiles`、`player`、`npcs`、`crops`、`fish`、`objects`、`buildables`、`tools`、`ui`。
- 状态：`default`、`locked`、`ruin`、`repairing`、`repaired`、`upgrade1`、`upgrade2`、`active`、`ready`、`depleted`、`completed`。
- 对象、NPC、作物、资源点会通过代码里的视觉描述 helper 暴露稳定 `id/state/assetPath/fallbackColor/label`，素材缺失时不影响玩法。

## 美术资源接入状态

- 开发面板的资源审计会同时显示“当前地图资源”和“后续预期资源”，并按 P0/P1/P2 标出已加载、缺失、优先级和推荐路径。
- 复制资源清单会输出当前地图描述、预期批次和缺口列表；`ART_RESOURCE_NEEDS.md` 仍是美术需求源文档。
- 作物路径：`assets/game/crops/<cropId>--active|watered|ready.png`；低矮作物按 `32x32`，小麦/豆子/番茄/玉米按 `32x48` 底部居中绘制。
- 村情设施路径：`assets/game/objects/communityFacility-<goalId>--ruin|repaired|upgrade1|upgrade2.png`，统一按 `96x80` 底部锚点绘制。
- 山里资源点路径：`assets/game/objects/resourceNode-<resourceId>--locked|active|depleted.png`；采石点/林缘 `64x64`，工具棚 `96x80`。
- 放置型建造物路径：`assets/game/buildables/<buildableId>--active.png`，缺图继续使用 Canvas 色块。
- 水产图鉴路径：`assets/game/fish/<fishId>.png`，缺图显示颜色圆点 fallback。

## 一年推荐节奏

- 春季：第一次出货、修复杂货铺、开放山里资源；春集和样本包可跨年补齐，保留约 `200g` 夏季启动资金。
- 夏季：稳定供货和社区订单，至少完成 1 个村民支线与 1 个村情目标。
- 秋季：修复加工、跑通加工品出货，加入合作社并完成首张合同。
- 冬季：补齐村情目标、推进至少 1 座设施强化二、完成合作社合同和 `300g` 现金，睡到大寒年终会。

## 设施升级路线

- 合作社路线优先强化冷链代收点，收益来自更高出货/出售收入和更低损耗。
- 乡村旅游路线优先强化老人互助饭点，收益来自更稳定的公共照护和体力上限。
- 品牌农产品路线优先强化青年返乡工坊，收益来自更低建造成本和后续包装/培训剧情。
- 水利与扩建路线优先强化村塘清淤点，收益来自水质提升和更多水产图鉴解锁。
