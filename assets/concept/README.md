## Generation Notes

- Mode: built-in image generation tool.
- Style target: locked three-quarter top-down 2D, painterly pixel-art-inspired, readable RPG environment layout.
- Shared constraints: no readable text, no UI labels, no watermark, grounded modern Chinese countryside, clear silhouettes for later Y-sort map production.

## Usage Rules

- Use these boards to guide map composition, zone adjacency, and asset silhouettes.
- Redraw final game assets at the required sprite/tile resolution rather than cutting directly from these boards.
- If a scene changes materially, generate a new versioned board instead of overwriting the current file.
